# shutdown (Power Down or Restart System)

## What is SHUTDOWN?

The `shutdown` command is a standard administrative utility used in Unix, Linux, macOS, and Windows operating systems to safely power down, halt, or restart a computer system.

# Examples & Usage

| Command | Description | 
| ----- | ----- | 
| `shutdown` | Shuts down the system after a default time delay (e.g., 1 minute) | 
| `shutdown now` | Shuts down the system immediately without waiting | 
| `shutdown +30` | Schedules a system shutdown to occur in 30 minutes | 
| `shutdown -r now` | Restarts the system immediately |
