# cat (Concatenate and Display)

## What is CAT?

The `cat` (concatenate) command is a standard command-line utility used in Unix, Linux, and macOS operating systems to read data from files and give their content as output, commonly used to view, combine, or create files in the terminal.

# Examples & Usage

| Command | Description | 
| ----- | ----- | 
| `cat <file>` | Displays the complete contents of a specified file in the terminal | 
| `cat <file1> <file2>` | Concatenates and displays multiple files sequentially | 
| `cat <file1> > <file2>` | Copies the contents of file1 into file2 (overwriting file2) | 
| `cat >> <file>` | Appends standard input to the end of a specified file |
