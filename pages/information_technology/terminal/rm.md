# rm (Remove Files or Directories)

## What is RM?

The `rm` command is a standard command-line utility used in Unix, Linux, and macOS operating systems to remove or delete files and directories from the file system hierarchy.

# Examples & Usage

| Command | Description | 
| ----- | ----- | 
| `rm <file>` | Deletes the specified file permanently | 
| `rm -r <directory>` | Recursively deletes a directory and its contents | 
| `rm -f <file>` | Forces the deletion of files without prompting for confirmation | 
| `rm -i <file>` | Prompts the user for confirmation before removing each file |
