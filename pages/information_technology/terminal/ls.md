# ls (List Directory Contents)

## What is LS?
The `ls` command is a standard command-line utility used in Unix, Linux, and macOS operating systems to list files and directories within the file system hierarchy.

# Examples & Usage

| Command | Description |
| :--- | :--- |
| `ls` | Lists files and directories in the current working directory |
| `ls -l` | Displays detailed (long format) listing including permissions, owner, size, and timestamp |
| `ls -a` | Shows all files, including hidden files starting with a dot (`.`) |
| `ls -h` | Displays file sizes in a human-readable format (e.g., K, M, G) |
