# mkdir (Make Directory)

## What is MKDIR?
The `mkdir` command is a standard command-line utility used in Unix, Linux, and macOS operating systems to create new directories or folders within the file system hierarchy.

# Examples & Usage

| Command | Description |
| :--- | :--- |
| `mkdir <directory>` | Creates a new directory with the specified name in the current location |
| `mkdir -p <path/to/dir>` | Creates parent directories as needed, preventing errors if they already exist |
| `mkdir -m 755 <directory>` | Creates a directory and sets specific access permissions upon creation |
| `mkdir -v <directory>` | Creates a directory and prints a verbose message for each created directory |
