# grep (Global Regular Expression Print)

## What is GREP?

The `grep` command is a powerful command-line utility used in Unix, Linux, and macOS operating systems to search text files for matching lines using regular expressions.

# Examples & Usage

| Command | Description | 
| ----- | ----- | 
| `grep <pattern> <file>` | Searches for a specific pattern within a file and displays matching lines | 
| `grep -i <pattern> <file>` | Performs a case-insensitive search for the specified pattern | 
| `grep -r <pattern> <directory>` | Recursively searches for the pattern in all files within a directory | 
| `grep -v <pattern> <file>` | Inverts the match, displaying lines that do *not* contain the pattern |
