# Terminal (Console and Command-Line Interface)

## What is a Terminal?

A terminal (often referred to as a console, command prompt, or shell) is a text-based interface used to interact with a computer's operating system. Unlike graphical user interfaces (GUIs) that rely on windows, icons, and mice, a terminal allows users to execute programs, manage files, configure system settings, and run administrative scripts by typing text commands directly into a command-line environment.

# Examples & Usage

| Interface / Component | Description | 
| ----- | ----- | 
| **System Console** | A physical or virtual dedicated text-input and output device directly connected to a computer system for administrative access | 
| **Terminal Emulator** | A software application (like GNOME Terminal, Windows Terminal, or macOS Terminal) that provides a shell interface within a GUI desktop | 
| **Shell (e.g., Bash, Zsh, PowerShell)** | The underlying command language interpreter that processes the text commands entered into the terminal | 
| **CLI (Command-Line Interface)** | The general architecture category for software that interacts exclusively through text lines |
