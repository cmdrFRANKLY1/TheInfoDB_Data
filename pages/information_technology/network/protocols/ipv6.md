# IPV6 (Internet Protocol version 6)

## What is IPV6?

IPv6 is the most recent version of the Internet Protocol (IP), designed to succeed IPv4. It uses a 128-bit address scheme to provide a vastly larger pool of unique IP addresses, along with improved routing efficiency, built-in security features, and simplified header structures compared to its predecessor.

# Examples & Usage

| Command / Format | Description | 
| ----- | ----- | 
| `2001:db8::1` | Standard compressed hexadecimal IPv6 address representation | 
| `ip -6 addr show` | Linux command used to inspect IPv6 network interface addresses and properties | 
| `ping -6 ipv6.google.com` | Tests network connectivity to a specific IPv6 address destination | 
| `traceroute6 ipv6.google.com` | Traces the network path taken by packets across an IPv6 network |
