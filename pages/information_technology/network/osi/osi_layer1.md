# OSI Layer 1: Physical Layer

## What is the Physical Layer?

The Physical Layer is the first and lowest layer of the Open Systems Interconnection (OSI) Model. It is responsible for the transmission and reception of raw, unstructured bit streams over a physical medium. This layer converts the logical 1s and 0s from the Data Link Layer (Layer 2) into electrical, mechanical, or optical signals and sends them across the network infrastructure. It defines the hardware elements of a network, including cables, voltages, pin layouts, and wireless radio frequencies.

# Examples & Usage

| Technology / Device | Description | 
| ----- | ----- | 
| **Ethernet Cables (Twisted Pair)** | Copper cables (e.g., Cat5e, Cat6) that transmit data using electrical voltage changes | 
| **Fiber Optics** | Glass or plastic threads that transmit data using extremely fast pulses of light | 
| **Wi-Fi (Physical RF)** | Wireless local area networking that uses radio frequencies to transmit data signals over the air | 
| **Hubs & Repeaters** | Simple hardware devices that regenerate and broadcast raw signals to all connected nodes without inspecting the data | 
| **Network Interface Card (NIC)** | The physical hardware component that connects a computer to a computer network (operates at both Layer 1 and Layer 2) |
