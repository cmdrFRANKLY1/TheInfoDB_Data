# OSI Layer 7: Application Layer

## What is the Application Layer?

The Application Layer is the seventh and topmost layer of the Open Systems Interconnection (OSI) Model. It serves as the direct interface between the network and the software applications used by the end-user. It is important to note that this layer does not refer to the actual software applications themselves (like Google Chrome, Microsoft Outlook, or Skype), but rather the communication protocols and APIs those applications rely on to send and receive data payloads over the network. It handles high-level functions like identifying communication partners, determining resource availability, user authentication, and synchronizing communication.

# Examples & Usage

| **Technology / Protocol** | **Description** | 
| ----- | ----- | 
| **HTTP / HTTPS** | The foundational protocols used for transmitting web pages, APIs, and web applications over the internet (HTTPS includes security) | 
| **SMTP / IMAP / POP3** | Standardized network protocols used for sending, retrieving, and managing electronic mail communications | 
| **FTP (File Transfer Protocol)** | A standard network protocol used for the direct transfer of computer files between a client and server on a computer network | 
| **DNS (Domain Name System)** | The hierarchical decentralized naming system that acts as a phonebook, translating human-readable domain names into IP addresses | 
| **SSH / Telnet** | Network protocols used to provide secure (SSH) or unsecure (Telnet) remote login and command-line execution on distant machines |
