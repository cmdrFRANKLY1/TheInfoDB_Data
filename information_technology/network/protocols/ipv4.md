# IPV4 (Internet Protocol version 4)

## What is IPV4?

IPv4 is the fourth version of the Internet Protocol (IP) and is a foundational core protocol of standards-based internetworking methods in the Internet and other packet-switched networks. It uses a 32-bit address scheme to uniquely identify devices on a network.

# Examples & Usage

| Command / Format | Description | 
| ----- | ----- | 
| `192.168.1.1` | Standard dotted-decimal IPv4 address representation for a local gateway | 
| `ipconfig` | Windows command-line utility used to display current IPv4 configuration details | 
| `ip addr show` | Linux command used to inspect network interface addresses and properties | 
| `ping 8.8.8.8` | Tests network connectivity to a specific IPv4 address destination |
